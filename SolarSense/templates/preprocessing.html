Pipeline

Data preprocessing & feature engineering

1

Raw dataset validation

Load the 11-column plant/weather CSV, verify schema and parse DATE_TIME.

2

Duplicate & missing value check

Row-level duplicate detection and per-column null counts, reported on the Dataset page.

3

Timestamp feature engineering

DATE_TIME is never fed to the model directly. It is decomposed into HOUR, DAY_OF_YEAR, MONTH, DAY_OF_WEEK, plus cyclical SIN_HOUR/COS_HOUR and SIN_DAY_OF_YEAR/COS_DAY_OF_YEAR encodings.

4

Categorical encoding

INVERTER_ID is label-encoded into INVERTER_ID_ENC using a mapping saved with the trained model, so the same inverter always maps to the same code at prediction time.

5

Feature selection

PLANT_ID and WEATHER_SENSOR_ID are excluded — both are constant in this dataset and carry no predictive signal.

6

Chronological train/test split

Rows are sorted by time; the earliest ~80% train the model, the most recent ~20% validate it — avoiding the temporal leakage a random split would cause.

7

Model training

Four regression candidates are trained on the primary feature set; the lowest-RMSE model on the validation split is selected and persisted.
